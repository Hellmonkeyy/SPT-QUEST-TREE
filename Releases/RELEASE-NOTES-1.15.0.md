# Quest Tracker 1.15.0

Install over 1.14.0 - replace both DLLs, keep your config.

## Seven boxes become one

A run of quests that follows in single file - each one unlocking exactly the next, all from one
trader, the way a Weapon Proficiency or Gunsmith sequence does - now draws as **one box**: the series
name, how many of the run are done, and a progress bar, coloured by the first quest in it still to
do. A `+` in the corner says there is more inside. Click the box to unfold the run; click the `–` on
its first quest to fold it again. The tree remembers what you opened for the session.

A run stays open on its own when something inside it needs seeing: a failed quest, a quest whose
prerequisite is not installed, a search hit of three or more letters on a quest's name, or a quest
you opened from the detail panel. With *Hide completed quests* on, a run you are part-way through
draws its remaining quests individually rather than as a box that would claim to hold the done ones.

The **Chains** button on the toolbar (or `C`) turns folding off and on; the setting persists.
